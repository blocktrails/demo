# Blocktrails Demo

Live demonstration of [Blocktrails](https://blocktrails.org) on Bitcoin testnet4.

## View Demo

**[blocktrails.org/demo/](https://blocktrails.org/demo/)**

## What This Shows

- A hardcoded demo key with visible state chain
- Genesis commitment at index 0
- Simulated state transitions (advance locally)
- Links to mempool.space/testnet4 for each address
