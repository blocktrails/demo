How Blocktrails Work

prev_key + sha256(state) = new_key → P2TR address

Each state chains from the previous key, mirroring Bitcoin's spend chain. The cryptographic chain is the state history — immutably ordered by Bitcoin.

This demo runs the earlier sha256(state) tweak. Spec v0.2 uses the BIP-341 TapTweak, which also binds each tweak to the previous public key.
